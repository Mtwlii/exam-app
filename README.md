# Exam App

A React + TypeScript exam application built with Vite.

## What is done
- Project set up with React 19, TypeScript, Vite, React Router, TanStack Query, React Hook Form, Zod, Tailwind CSS 4 and shadcn/ui
- Application shell (`src/App.tsx` is still a stub, so features are not built yet)

## Getting started
```
npm install
npm run dev
```
Other scripts: `npm run build`, `npm run lint`, `npm run preview`.
